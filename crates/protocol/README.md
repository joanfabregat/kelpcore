# Kelp terminal protocol

Portable terminal wire types, version constants and cell validation shared by the [server](../server) in the [KelpServer repository](../../README.md) and its clients, including the Rust/WASM client in [KelpMux](https://github.com/joanfabregat/kelpmux). This crate has no server, client presentation or WASM dependency. Terminal stream version 1 and local protocol version 58 are unchanged by the extraction.

See [stream documentation](../server/docs/native-client-protocol.md), [contribution policy](../../CONTRIBUTING.md), [security policy](../../SECURITY.md) and the repository [Apache-2.0 license](../../LICENSE).
